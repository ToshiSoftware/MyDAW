# MyDAW — プロフェッショナル オーディオ ワークステーション for Mac（Apple Silicon）

**バージョン 2.2** ・ [English README](README.md)

MyDAW は、Apple Silicon Mac 向けのマルチトラック・オーディオ録音／編集／ミキシング DAW（Digital Audio Workstation）です。Core Audio（AVAudioEngine / Core Audio HAL）を基盤とし、Audio Unit と VST3 のエフェクトを使用できます。

## 主な機能

### 録音
- 24-bit Linear PCM WAV（44.1 / 48 / 88.2 / 96 kHz）、モノラル／ステレオ、ディスク直書き。
- トラックごとに Core Audio デバイスの入力チャンネルを選択。
- 録音位置をサンプル単位で補正（自動＋手動の遅延補正）。
- **パンチイン／アウト**: パンチ範囲だけを録音。録音は通しで保存されるので、後から範囲を広げられます。
- **録音時のロールバック**（P の右の ↺ ボタン）: 通常録音のとき、再生位置から指定した小節数（1〜16、設定画面で指定）だけ戻って再生し、元の再生位置から録音します（クリップの開始点が決められます）。戻った部分もファイルには録音されているので、クリップの左端をドラッグすれば取り出せます。
- **R キー**で録音待機中のトラックに録音を開始（赤い録音ボタンと同じ。再生・録音中なら停止）。
- **インプットモニタリング**（`I` ボタン）: 録音待機中の入力を、トラックのエフェクトを通して試聴（録音は原音）。
- メトロノーム（BPM、小節・拍ルーラー、クリックのタイミング・音量調整）。ON／OFF は再生中・録音中も切り替えられます。メトロノームボタンの右クリックで音量のフェーダーが開き、再生中も音量を変えられます。
- **曲の開始・終了フラグ**（ルーラー）: 先頭へ戻るで開始フラグへ（もう一度で 00:00 へ）、終了フラグで再生・録音を停止、書き出し範囲の初期値にも使います。
- 録音済みのトラックでもモノラル／ステレオを切り替え可能。ファイルは書き換えません（モノラルのトラックではステレオのクリップを (L+R)/2 で再生）。
- 再生位置の ● が拍ごとに跳ねます（再生中は緑、録音中は赤）。ルーラーのクリックによる再生位置の移動もスナップに従います。

### 編集
- クリップの移動（トラック間も可）、両端のトリム、クリップゲイン、フェードイン／アウト、分割、複製、削除、ミュート。
- **複数選択**: shift／cmd＋クリック、枠選択（shift で追加）、cmd+A。選択したクリップはまとめて移動・削除できます。
- **右クリックメニュー**: 選択していないクリップを右クリックするとそのクリップを選択し、選択中のクリップを右クリックすると選択中のすべてのクリップに働きます（ノーマライズ、逆再生、ミュート、複製、分割、削除。複数のときは項目に個数を表示）。複製は選択をかたまりのまま再生位置へ置きます。範囲選択の内側では範囲用のメニューになります。
- **範囲選択**（cmd＋ドラッグ）: 複数トラックにまたがる時間範囲を選び、削除（無音化）、切り出し（Crop）、両端で分割。
- **カット／コピー／ペースト**（cmd+X / C / V、再生位置へ貼り付け）、option＋ドラッグで複製。
- **操作部のポインタ**: クリップの端（開始 →／終了 ←）、フェードの点とカーブ（指）、ゲイン（上下矢印）に重ねるとマウスポインタの形が変わり、どこをつかめるかが分かります。
- **フェードカーブ**: フェード線中央のつまみをドラッグして形を連続的に変更（直線・等パワーに吸着、ダブルクリックで Auto）。
- **ノーマライズ**（クリップゲインで 0 dBFS に）、**逆再生**（逆向きの WAV を作成して差し替え）。
- ドラッグ中はフェード長・ゲイン（dB）・カーブをツールチップで表示。波形はフェードやクロスフェードを反映した音量で描画。
- クリップ編集の UNDO／REDO、拍へのスナップ。
- **重なり処理**: 後から追加したクリップが古いクリップより優先され、境界にはクロスフェード（既定は等パワー）が自動で付きます。上のクリップのフェードがそのままクロスフェードになります。
- **トラックの並べ替え**: トラックヘッダの空いている所（トラック名やメーターなど）をつまんで上下にドラッグ。落とし先は白い線で示します。ミキサーのストリップも同じ順に並びます。
- **トラックフォルダ**: トラック一覧の「＋」メニューまたはヘッダの右クリックで**フォルダを追加**し、トラックをドラッグして入れます（入れたトラックは右へインデント。線がインデントしていればフォルダ内に入ります）。▼／▶ でフォルダを開閉でき、閉じたフォルダのトラックは描画しません（再生・録音はされます）。フォルダの [M]／[S] は中のトラックをまとめてミュート／ソロにし（そのトラックのボタンはグレーで点灯）、オフにすると各トラックの元の状態に戻ります。フォルダはトラックと一緒にドラッグで移動、色の変更、ダブルクリックで名前の変更ができます。入れ子にはできません。
- **ヘッダの右クリックメニュー**: トラックを右クリックするとカレントにし、その上に**トラックを追加**／**フォルダを追加**（フォルダ内のトラックではトラックのみ）、**ミキサーに表示**（ミキサーをスクロールしてそのトラック・フォルダを左端に表示）。
- Finder から WAV をドラッグ＆ドロップで取り込み。サンプルレートやビット数が違うファイルは、今のサンプルレートの 24-bit WAV に変換して取り込みます。
- 細かい波形表示: 1pt ごとの最小〜最大の棒で描き、強く拡大したときはサンプルそのものから描くので、1 周期ずつの波が見えます。
- タイムラインは曲の長さ（クリップと終了フラグ、最低 60 秒）で、それより先は暗く表示します。ルーラーのクリックや再生しっぱなしでは延びません。
- 表示: ルーラー上のホイール／ピンチで時間方向の拡大縮小（5〜3200 px/秒）、option＋ホイールでトラックの高さ、option+shift＋ホイールで波形の縦倍率。
- **自動スクロール**: 再生・録音中に表示が再生位置を追いかけます。トランスポートバー右端の |→ ボタンで ON／OFF。横スクロールバーはつまみ（●）のドラッグでだけ動きます。

### ミキシング
- Studio One 風ミキサー。各ストリップは **INSERT**、**SEND**、**コントロール** の 3 区画で、高さを変更できます。ミキサー全体の高さは上端のドラッグで変更でき、SEND とフェーダー部の境目から下端までは 220pt 以上に保たれます。ウインドウを縮めると縮むのはトラックの表示部分だけで、トランスポートバーとミキサーは欠けません。ミキサーのバーの ▼ でミキサーをたたみ（バーだけを表示）、▲ で元に戻します。
- カレントトラックは、ミキサーの名前欄が白地に黒文字で表示されます。フォルダの始まりと FX チャンネルの始まりには色の縦線が入り、クリックで色を変更できます（FX の線の色はすべての FX チャンネルに適用され、新しい FX もその色で作られます）。
- dB 目盛りのフェーダー（最大 **+6 dB**）、ピークホールド付き L/R ステレオメーター、横 PAN、ミュート／ソロ、数値のダブルクリック入力。
- トラック、FX チャンネル（名前変更・ミュート／ソロ可）、マスター。Send はインサート後・PAN 後。FX をソロにすると、その FX の音だけが鳴ります。新しい FX の名前は、既存の「FX 番号」の最大値の次の番号になります。
- トラック色をパレットから変更。

### プラグイン
- Audio Unit と VST3 のエフェクトを、トラック・FX・マスターに任意の順で挿入。
- VST3 はオーディオグラフ内でリアルタイム処理され、GUI での変更がすぐに音に反映されます。
- VST3 の検出は別プロセス＋キャッシュで実行。同じ製品の AU 版がある VST3 は、衝突を避けるため一覧に表示しません。
- **プラグインの遅延補正**：トラックのインサートと FX チャンネルの両方を補正します。FX チャンネルに遅延の大きいプラグイン（マスタリング用など）を挿しても、元の音とエフェクト音がずれません。プラグインをバイパスしても補正は変わらず、設定で遅延が変わるプラグインにも追従します。
- 再生開始位置の音は最初のサンプルから鳴ります（メトロノームの最初のクリックも）。
- プラグイン設定のプロジェクト保存。

### プロジェクト
- プロジェクトは `.mydaw` ファイルと、同じ場所の `Recordings/` フォルダー（例: `MySong/Ballad.mydaw` と `MySong/Recordings/`）。ファイル名とフォルダー名は自由で、フォルダーごと別の Mac へ移行できます。1 つのフォルダーに複数の `.mydaw` を置くと `Recordings/` を共有します。**名前を変えて保存**（⇧⌘S）は同じフォルダーにのみ保存します。Finder で `.mydaw` をダブルクリックすると、そのプロジェクトが開きます（ファイルには MyDAW の書類アイコンが付きます）。
- 起動画面の**最近使ったプロジェクト**: 最大 50 件を最後に保存した日時とともに表示し、名前をクリックすると開きます。
- マスター出力の書き出し。ダイアログでファイル名・保存先・形式を指定し、WAV（16／24-bit）または MP3（固定ビットレート／VBR）、44.1／48／96 kHz（MP3 は 48 kHz まで）で書き出します。開始・終了位置でサンプル単位に正確に切り出します（プラグインの遅延も補正）。マスターをリアルタイムで書き出してから変換します。
- **未使用の録音ファイルの移動**: プロジェクトで使われなくなった `Recordings/` 内の WAV（削除したパンチのテイクなど）を `Recordings/Unused/` へ移動します。同じフォルダーのほかの `.mydaw` が使っているファイルは残します。

### オーディオデバイス
- 入力と出力に別々のデバイスを選択可能（例: 入力はオーディオインターフェース、出力はモニターのスピーカー）。MyDAW の起動中は選んだデバイスを macOS の既定の入出力に切り替え、終了時に元に戻します。
- デバイスやサンプルレートを変更すると、保存して再起動するかを確認し、再起動後にプロジェクトを開き直します。
- ステータスバーの **CPU 表示**: オーディオ処理の負荷をバーで表示し、緑→黄→オレンジ→赤と色が変わります。音飛びが起きると赤い **●音飛び** を 3 秒間表示します。

### 表示言語
- ヘルプメニューの **MyDAW ヘルプ**（⌘?）で、表示言語に合わせた操作マニュアル（PDF、Web）を開きます。
- 画面は日本語と英語に対応。初期値は macOS の言語設定に従い、設定画面の「言語」で切り替えられます（再起動後に反映）。
- 翻訳は `Resources/ja.lproj`・`Resources/en.lproj` の `Localizable.strings`。日英対照表は [docs/UI_Strings_en_ja.csv](docs/UI_Strings_en_ja.csv)。GUI の文字列を追加したら `./scripts/extract-strings.sh` で翻訳漏れを確認します。

## ビルドと起動

正式なビルド手順はシェルスクリプトです。

```bash
./scripts/build.sh      # VST3 ブリッジ（CMake）、MP3 エンコーダ（LAME）、アプリをビルド
open build/MyDAW.app    # 起動

./scripts/run.sh        # ビルドして起動
```

> Xcode でもビルドできます。`MyDAW.xcodeproj` を開いて Product > Build（⌘B）を実行するか、`xcodebuild -project MyDAW.xcodeproj -target MyDAW -configuration Release build` を実行してください。成果物は `build/Release/MyDAW.app` です。最初のビルドフェーズで VST3 ブリッジを CMake でビルドするため、CMake を `/opt/homebrew/bin` か `/usr/local/bin` に入れておく必要があります。MP3 エンコーダは後のビルドフェーズで `scripts/build-lame.sh` により組み込まれます。`Package.swift` は現行ソースに追従して**いません**。

Google Drive のフォルダー内でビルドする場合、スクリプトが署名前に拡張属性を取り除きます。

## クイックスタート

1. MyDAW を起動し、**New Project**（保存パネルで保存先と名前を指定）または **Open Project**（`.mydaw` ファイルを選択）を選びます。**最近使ったプロジェクト**の一覧から開くこともできます。
2. macOS がマイクへのアクセスを求めたら許可します。
3. 歯車ボタンで入出力デバイスとバッファサイズを選びます。
4. トラックの **R** をオンにして入力チャンネルを選び、メーターが動くことを確認します。
5. 赤い **Record** ボタン（または **R** キー）で録音を開始し、**Space** で停止します。
6. **Space** で再生します。画面下のミキサーで音量を調整します。

詳しい手順は [操作マニュアル](OperationManual_jp.pdf) を参照してください。

MP3 エンコーダには [LAME](https://lame.sourceforge.io/) 3.100（LGPL）を使っています。`scripts/build-lame.sh` がソースをダウンロードし（SHA-256 で確認）、`libmp3lame.0.dylib` をビルドします。このライブラリは差し替え可能な別ファイルとして `MyDAW.app/Contents/Frameworks` に入り、ライセンスは `Contents/Resources/LAME-COPYING.txt` に入ります。このため、最初のビルドにはインターネット接続が必要です。

## 既知の制約

- インストゥルメント（音源）は、AU・VST3 とも対応していません（エフェクトのみ）。MIDI で操作するタイプの AU エフェクト（ミュージックエフェクト）も一覧に表示されません。
- FX チャンネルに遅延の大きいプラグインを挿すと、入力モニターの音もその分遅れて聞こえ、再生の開始もその分だけ遅くなります（録音される音には影響しません）。
- 読み込んだ後に遅延が変わる VST3 プラグインには追従しません（AU は追従します）。
- デバイス、サンプルレート、表示言語の変更は、MyDAW の再起動後に反映されます（変更時に再起動を確認します）。
- 再生中にインプットモニター（I）を切り替えた場合、反映は停止後になります。オンにした場合は停止後に残響が消えてから入力の音が聞こえ始め、オフにした場合は停止まで入力の音が聞こえ続けます（再生中はモニターの接続を切り替えられないため）。
- MyDAW の起動中は、選んだデバイスが macOS の既定になるため、ほかのアプリの音も同じデバイスから出ます。MyDAW が異常終了した場合は既定デバイスが元に戻らないため、システム設定の「サウンド」で戻してください。
- プラグインの挿入・削除・並べ替えは停止中のみ可能です。
- プラグインの専用画面が 3 秒以内に応答しない場合は、汎用のパラメーター画面（Generic UI）で表示します。

## バージョン

現在の About ダイアログのバージョンは **2.2** です。v2.2 では、書き出しを保存パネルから書き出しダイアログ（ファイル名・保存先・形式）に変え、MP3 書き出し（固定ビットレート／VBR）と、16-bit WAV・44.1〜96 kHz の選択を追加しました。v2.1 では、トラックフォルダ、トラックヘッダの右クリックメニュー、ミキサーをたたむボタンなどを追加しました（フォルダを含むプロジェクトは v2.0 で開くとフォルダが失われます）。v2.0 では、プロジェクトをフォルダーではなく `.mydaw` ファイルで指定するようになり、ファイル名とフォルダー名を揃える必要がなくなりました。
