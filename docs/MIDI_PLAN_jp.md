# MyDAW V4.0 MIDI 機能 開発計画

作成：2026-11-03　対象バージョン：**V4.0**　UI モデル：一般的な DAW のピアノロール

## 1. 機能の整理

### 1.1 初回（V4.0）に入れるもの

| 区分 | 機能 |
|---|---|
| トラック | インストゥルメントトラック（新しいトラック種別）。ミキサー・インサート・Send・フォルダ・M/S はオーディオトラックと同じ |
| インストゥルメント | AU インストゥルメント（`aumu`）の検出・選択・差し替え、専用 GUI（ない場合は Generic UI）、状態のプロジェクト保存 |
| MIDI クリップ | アレンジャー上の表示（ノートの縮小表示）、移動・コピー・分割・トリム・削除・ミュート、UNDO |
| ピアノロール | 鍵盤、ノートグリッド、ルーラー、ツール（矢印・鉛筆・消しゴム・ミュート・試聴）、ノートを試聴、範囲選択・複数選択、コピー／ペースト、上下キーで移調、ズーム |
| ノートの編集 | 追加・削除・移動・長さ変更、デフォルトのベロシティ、入力する長さ（1/16 など・ストレート／3 連）、スナップ |
| 調整機能 | クォンタイズ（グリッド・強さ・開始／終了）、長さ（固定長・レガート）、ベロシティ（固定・比率・相対）、移調 |
| ベロシティ編集 | 下部のベロシティレーン（バーのドラッグ、線で一括描画）、ベロシティによるノートの色 |
| リアルタイム入力 | MIDI 鍵盤のモニター（録音待機中のトラック）、録音（カウントイン／ロールバック、パンチと連動）、重ね録り／置き換え |
| SMF 取り込み | Format 0/1。SMF のトラックごとにインストゥルメントトラックを作成。テンポは先頭の値を採用するか選ぶ |

### 1.2 初回は見送るもの

- VST3 インストゥルメント（テスト用の VST 専用音源がないため、その時点で相談）
- マルチアウト（ドラム音源のパラアウトなど）。初回はメインのステレオ出力のみ
- CC・ピッチベンド・アフタータッチの編集レーン（保存と再生はする）→ 2026-11-04 にピッチベンド・モジュレーション（CC1）・アフタータッチを追加（進捗記録）
- テンポチェンジ、SMF 書き出し、フリーズ／バウンス、ステップ入力、ドラムエディター、MIDI エフェクト（`aumf`）

## 2. 設計の要点

1. **ノートの時間は拍（ティック、960 PPQ）で持つ。** オーディオクリップ（秒）と違い、テンポを変えても小節に沿う。
2. **音源の位置**：オーディオトラックの TrackRenderer の代わりにインストゥルメントの AU を先頭に置き、以降（フェーダー → インサート → PAN → 分岐）は既存のチェーンを使う。
3. **再生のスケジュール**：インストゥルメントの描画の直前に、そのバッファ内のイベントを `scheduleMIDIEventBlock` でサンプル単位のオフセット付きで送る。メインスレッドで作った再生計画だけを読む。
4. **遅延補正**：クリップと同じく「トラックのインサートの遅延 ＋ D」だけ早めて送る。インストゥルメント自身の遅延も加える。
5. **停止・頭出し**：All Notes Off とサスティンのオフを送る。再生開始時はその位置のサスティン・ピッチベンド・プログラムを先に送る（チェイス）。
6. **MIDI 入力**：CoreMIDI で全入力ソースをまとめて受ける（鍵盤は 1 台）。録音はホスト時刻をタイムラインの拍に変換し、モニターの遅延分を補正する。
7. **保存形式 v6**：トラック種別、MIDI クリップ、インストゥルメントの状態を追加。v3.1 で開くとインストゥルメントトラックは失われる（既知の制約として記載）。
8. **拍子（3/4・5/4 など）**：実装済み（2026-11-07）。プロジェクトに 1 つ、分子 1〜16・分母 4 か 8、BPM は 4 分音符のまま。トランスポートバーの拍子欄で設定し、プロジェクトに保存する。ノートは拍（ティック）で持つので、拍子を変えても動かない。小節に関わる計算はすべて `MusicalMeter` を通す。曲の途中での拍子の変更はない。
9. **既知の落とし穴**：AU v2 の既定バスレート（確保前にフォーマットを設定）、再生中の接続は保留されうる（音源の差し替えは停止中のみ）、重い音源（大きなドラム音源）は読み込み中表示で UI を止めない、プラグインウィンドウの重なり順を音源 GUI にも適用。

## 3. テスト用インストゥルメント

| 用途 | 音源 | 形式 | 備考 |
|---|---|---|---|
| Drums | マルチアウトのドラム AU | AU | 読み込みが重い。マルチアウトあり（初回はメイン出力のみ） |
| Bass | ベース AU | AU | |
| Piano | ピアノ AU | AU | AU の表示名の末尾が「(0->2)」（入力 0／出力 2 のステレオ版と思われる） |

MIDI 鍵盤は 1 台。
